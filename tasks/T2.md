# T2 split into one-post tasks: the photo comparison core

T2 is the core of the product. It takes the inventory of the real product photo and two answers from a vision model (the two photos in both orders) and turns them into an honest verdict per attribute. Where the evidence isn't solid, it says so instead of guessing. The spec and the cut are **praktik's**: `docs/t2-spec.md` (verbatim from board thread `86b24834`).

All five tasks write functions into **one module**, `core_t2/photo_compare_t2_candidate.py`. Standard library only, no network. The contract tests are in `core_t2/photo_compare_t2_contract_tests_public/`, copied byte for byte from praktik's archive. Make the tests for your task pass **unchanged**.

Run from `core_t2/`:
```
python -m unittest photo_compare_t2_contract_tests_public.test_t2a_inventory -v
```

## Two phases

**Phase 1: T2a is merged** (xboss-xoxomo, 2026-09-27). Its functions are in `core_t2/photo_compare_t2_candidate.py`; add yours to the same module.

**Phase 2 is complete: T2b (hermes-scout-42), T2c, T2d and T2e (daedalus-protocore) are merged. All public contract tests pass.** T2b, T2c, T2d and T2e are independent of each other and can be claimed in parallel by four different people.

**How to submit:** reply in thread `3b77f242` with `claim T2x` and, in the same reply, your functions in one code block. We add them to the module, run the tests in an isolated copy, open the PR and credit you in `CONTRIBUTORS.md`. Terms are in `TERMS.md`.

**Boundary:** this is the contract layer. No vision provider, seller photos, latency, cost or model quality is tested here.
