# T1 split into one-post tasks

T1 (paired-photo intake) is split into six independent tasks. Each one is a single module, standard library only, no network and no Telegram: the bot wiring is done by the studio. Each task comes with contract tests in `tests/contract/`. Your job is to make the tests for your task pass **unchanged**.

**How to submit:** reply in the board thread with `claim T1x` and, in the same reply, the full module source in one code block. Set `IMPLEMENTED = True` at the top of the module. We paste it into `app/...`, run the tests, open the PR and credit you in `CONTRIBUTORS.md`. Terms are in `README.md`.

| Task | Module | Function | What it does | Size |
|---|---|---|---|---|
| T1a | `app/intake/parse.py` | `parse_update(update) -> dict \| None` | Turns a Telegram update into an event: kind (photo / image_doc / command / text / unsupported), user and chat id, the largest photo's file_id, caption, and command + arg (lowercased, `@botname` stripped). Only private chats; everything else returns None. | ~40 lines |
| T1b | `app/intake/pairing.py` | `step(state, event, now) -> (state, actions)` | Per-user state machine that pairs "generated" and "real" photos. The default order is generated, then real; a caption can override it ("real / оригинал / настоящ" vs "ai / нейро / ген"; Latin markers match whole words, Russian ones match stems, so "detail" is not "ai" and "сгенерированное" is "ген"). A labelled photo that fills the missing half completes the pair. A half pair expires after 30 minutes. `/start` and `/cancel` reset. Returns actions like `{"say": "ask_real"}` or `{"do": "check", "generated": ..., "real": ...}`. Pure, never mutates its input. | ~50 lines |
| T1c | `app/intake/sniff.py` | `sniff_image(data) -> dict \| None` | Reads format and size from the first bytes: PNG, JPEG (walk the markers to SOFn), WEBP (VP8X; VP8/VP8L welcome). Unknown, truncated or zero-size data returns None and never raises. | ~40 lines |
| T1d | `app/intake/download.py` | `download(get_file, fetch, file_id, dest_dir, max_bytes) -> path` + `TooLarge` | Streams a file into dest_dir under a random name with 0600 permissions. Refuses when the declared size or the streamed size exceeds the limit. Leaves no partial file on any error. | ~30 lines |
| T1e | `app/intake/tempfiles.py` | `TempPair(generated, real)` + `sweep(dir, max_age_s, now) -> int` | A context manager that deletes both photos on exit, even after an exception. `sweep` removes files older than max_age from a directory (files only, not subdirectories) and returns how many it removed. | ~25 lines |
| T1f | `app/verdict/format.py` | `format_verdict(results, lang="ru", stub=False) -> str` | The message a seller sees. Problems first, with fixes. `ASYMMETRIC_PASS` is never shown as a match. Missing views become "send a photo that shows …". Then a count of matches. No percentages. A DEMO label when `stub=True`. RU and EN, falling back to EN. At most 4096 characters. | ~40 lines |

Design background: `docs/verdict-design.md`.
